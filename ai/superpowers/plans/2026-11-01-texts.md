# Plan: texts and UX labels (MY-325)

Branch `my-325-texts`. What a visitor sees is in `ai/superpowers/specs/2026-11-01-texts.md`.

## Cause

Several labels say something the control does not do (a "Download" that opens the contact form), three "View All"
buttons name a different page than the one they open, one action ("open the post") has two names, the phone field starts
on India while every phone on the site is `+1`, and a few strings differ in style from their neighbours.

## Rules the choices follow

- The site has no files and no backend (`contact-form-without-backend`, `placeholder-content`): a button never promises a
  file. A label names the place the button leads to.
- One action has one name wherever it shows (`jsx.md`): one label in `data/ui-labels.js`, read by every card.
- The design is a visual reference (`design-is-a-reference`): the strings below follow the site's real behaviour, so they
  differ from the design's on purpose; the layout does not change.

## Changes

1. `data/resources.js`: the two showcase `cta`s, `previewLabel`, `downloadLabel`.
2. `data/pages.js`: the Resources description, the 404 title.
3. `data/blogs.js`, `data/news.js`: the three heading-band links.
4. `data/ui-labels.js`: `readMore` stays, `viewBlog` goes; `listenPodcast` text becomes "Listen Now".
   `PostRow.jsx` reads `readMore` (the one JSX line a text change needs).
5. `data/faq.js`, `data/cta.js`, `data/contact-form.js`: strings.
6. `data/countries.js`: the United States first, `defaultDialCode = '+1'`. `PhoneField` and the controller read the default
   from the data, so no code changes.
7. `data/ui-kit.js`: the demo strings.
8. `ai/design-system.md`: the rows that quote the changed strings.
