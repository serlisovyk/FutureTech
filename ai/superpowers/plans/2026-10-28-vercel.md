## Config

```json
{
  "cleanUrls": true,
  "trailingSlash": false,
  "headers": [
    {
      "source": "/assets/(.*)",
      "headers": [
        { "key": "Cache-Control", "value": "public, max-age=31536000, immutable" }
      ]
    }
  ]
}
```

- `cleanUrls` maps `/news` to `dist/news.html` and redirects `/news.html` to `/news` (308).
- `trailingSlash: false` redirects `/news/` to `/news`.
- `/assets/*` is where minista writes every hashed file (fonts, CSS bundle, script), so it is safe
  to cache for a year as `immutable`. HTML keeps Vercel's default, which revalidates.
- The 404: minista builds `dist/404.html` from the `404` page, and Vercel serves a `404.html` from
  the output directory for paths that match nothing, so no `routes` or `rewrites` entry is added.
- The output directory is `dist` already in production; no `outputDirectory` field.
