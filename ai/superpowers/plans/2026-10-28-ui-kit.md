# Plan: the UI kit and the `/ui` page (MY-256)

Branch `my-256-ui-kit`. Records cited: `styles-next-to-components`, `fluid-ramps`, `path-aliases`,
`page-head-and-entries`, `image-formats`, `ci-size-limit` (its limits are raised here, see "Size"). minista API
used: `Head` from `minista/head` (already used by every page), `Sprite` and `Picture` through `Icon` and
`Photo`; checked against the guide `minista agents` prints for the installed version. No spec: the kit is static
markup and styles, nothing a user does changes.

## Scope

JSX components with a stylesheet each beside them, one demo page, one demo section, docs. No browser script.

| Component        | Renders                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------ |
| `Button`         | `<a>` with `href`, else `<button>`; `variant` `primary` or `outline`; optional `icon` name |
| `Tag`            | the small plate above a section title                                                      |
| `SectionHeading` | the heading band: `Tag`, `Heading`, optional "View All" outline `Button`; stacks at Mobile |
| `Stat`           | a number with a yellow "+" over a caption; `isLarge` for the Resources counters            |
| `MetaItem`       | a grey label over a white value; `isCard` draws the surface                                |
| `MetaGrid`       | a `<dl>` that lays `MetaItem`s out in a row, stacked cards at Mobile                       |
| `CounterPill`    | an icon and a number with a visually hidden name; `isLiked` for the red heart              |
| `Badge`          | the "New" mark with the gradient border                                                    |
| `AvatarGroup`    | overlapping round photos in a rounded box                                                  |

`/ui` is `src/pages/ui.jsx`, which renders the section `sections/ui/UiKit.jsx` (page files hold no markup,
`ai/rules/architecture.md`): every component and every variant, so `minista build` and `check` cover all of them.

## Decided

- **`/ui` ships** (author, 2026-10-28): committed, deployed, `noindex` in its `Head`, linked from nowhere.
  Recorded with the size limits.
- **The heading band belongs to `SectionHeading`**: fill, the two borders and the 120 / 80 / 40 block padding are
  drawn on the frame that holds the tag, title and button, so the component is the band and its content sits in a
  `.container` (`ai/rules/css.md`, dividers). A tabs row or a paragraph beside the title is not in the issue.
- **`Button` has the sizes of the buttons the design names for each variant:** primary is the Contact Us button
  (the Send button is wider and is the form task's), outline is "View All". A ghost button (fill `Dark/10`) is not
  in the issue. Hover is not drawn (`ai/design-system.md`), so none is invented; focus is the base ring.
- **`MetaItem` has two looks the design draws:** the plain pair (Blog sidebar, News story) and the card (Podcasts,
  Resources). `MetaGrid` is one flex row; a card has `flex: 1` and takes the full width under 768 px, so it needs no
  prop. The plain pair's gap in the design is 20 flat or 50 / 30 / 20 and the card's 20 / 16 / 14: one ramp, 20 / 16 / 14.
- **`CounterPill` is a static `<span>`.** It shows a count; a like that can be toggled is behavior and comes with
  the section that stores it. `icon` is a sprite name; `isLiked` swaps it for `heart-filled`, drops the surface and
  colours it `--color-like`. A count is rendered as given: formatting `24500` as "24.5k" is the sections' helper.
- **`Stat` splits a trailing "+"** off the data value (`'300+'`) to colour it, so `data/stats.js` stays as it is.
- **`AvatarGroup` takes the "Downloaded By" cluster**: box `Dark/08`, radius 12, avatars 50 / 40 / 40 with a 2 / 1 / 1
  ring `Dark/40`, overlap 9. The hero capsule (larger avatars on `Dark/10`) is not in the issue. The photos are
  decorative (`alt=""`): the number beside them says the same.
- **Avatar sources** are the four portraits of the Ebooks group, copied from the design's export into
  `assets/images/` under the names `data/resources.js` already uses (PNG: the cutouts carry alpha). The second
  group is not rendered on `/ui`, so it is not copied.
- **No new tokens:** `--font-size-button`, `--radius-pill`, `--border` and `--space-container` already cover what two
  blocks share; every other value is one block's and is written there.

## Size

`npm run size` before: JS 981 B, CSS 1.06 kB, fonts 111.63 kB. `/ui` renders the kit, so the CSS grows and its
limit is raised by fact (measured, rounded up, small headroom) in a new record with an `Images` entry for the
avatars (`dist/assets/*.{avif,webp}`, no gzip or brotli). JS and fonts do not change and keep their limits.
