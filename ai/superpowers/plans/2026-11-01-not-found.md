# Plan: the 404 page (MY-310)

Branch `my-310-not-found`. The behavior is in `ai/superpowers/specs/2026-11-01-not-found.md`.

## Cause

`pages/404.jsx` renders a bare `h1` and `p` with no container and no styles, so the text sits against the left edge
under the header, and nothing leads back to the site.

## Placement

The page needs the look of the intros of News, Podcasts and Resources, which `PageIntro` already draws: the `display`
title over two lines, the text beside the second line, the container and the spacing at every width. So the page reuses
it and adds no second block with the same rules.

- `PageIntro` takes an optional `children`: an action row under the text, in the text's column (below 768px in the single
  column). It renders only when given, so the three existing intros stay as they are. The new rule is one element,
  `page-intro__action`, and a media override that follows the text's.
- A section is needed (a page lists sections, never markup: `architecture.md`), so `NotFoundIntro` is added, as
  `NewsIntro` is, in a new group `sections/not-found/` (the group of a page whose sections no other page uses, as `news/`
  is). It composes `PageIntro` and the kit `Button` (primary, `ui/arrow-up-right`, the link to `/`).
- Rejected: extending `PageIntro` with `actionLabel` / `actionHref` props (it would own a button for one page; the slot
  keeps the kit's `Button` in the section that wants it); a section with its own title markup and stylesheet (a copy of
  the intro's rules, and the CSS budget is nearly spent).

## Changes

1. `data/not-found.js`: `notFound` holds `titleId`, `titleStart` ("Error 404:"), `titleEnd` ("Page Not Found"), `text` and
   the button's `actionLabel` and `actionHref`. It is passed by name, not spread (`spread-of-a-data-item`): it is the
   section's own fields, not `PageIntro`'s props. `pages.notFound` stays as it is (`noindex`).
2. `components/page/PageIntro/`: the `children` slot and `page-intro__action`.
3. `sections/not-found/NotFoundIntro/` (the folder, `NotFoundIntro.jsx`, `index.jsx`), the group's `index.jsx`, a line in
   `sections/index.jsx` (`section-parts-in-folders`).
4. `pages/404.jsx`: `metadata` and `<NotFoundIntro />`.
5. Docs: `ai/map.md` (the group, the slot), within its 12 KB limit.

## CSS budget

The CSS is 11.29 of 11.5 kB gzipped. The new rules are about 100 bytes of source, so the limit is expected to hold; if the
measured size goes over, `.size-limit.json` is raised by fact and a dated record follows the earlier `*-size-limits`.

## Verification

The checks under "Verification" in `AGENTS.md`. `dist/404.html` read for `noindex`, one `h1`, the link to `/`; `vercel.json`
serves `404.html` for unknown paths (Vercel's default for a project with a built `404.html`; the config is not touched).
In `npm run dev`: `/404` and an unknown path at 1920 / 1440 / 1024 / 768 / 390 against `/news`'s intro for the spacing,
no horizontal scroll at 390, Tab to the button with the ring visible, Enter to `/`.
