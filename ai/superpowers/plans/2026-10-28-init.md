## Decisions made here

- **Page head:** the title is `metadata.title` of the page, rendered by the layout; the
  description is a `<meta>` inside the page's `Head` (the metadata type has no description
  field). Alternatives rejected: a `getStaticData` prop per page (indirection for one string).
- **CSS:** imported by the layout (and later by each component) so Vite bundles it into one file,
  the way the styling guide calls usual; not a `<link>` per file.
- **Client JS:** one entry, `main.js`, as a module script in the layout's head; React is not
  bundled because no page or component script imports it.
- **Stub titles:** `<Name> | FutureTech`, literal in each page until the real sections and a
  metadata pass replace them.
